## First run (testing method)

1. Fork or clone public repo (optional).
2. Place system files where the AI can read them (Drive / local / connectors).
3. Copy **User-Record-Template.md** → **User-Record.md**; fill roots and journal folders only.
4. Use **Blank-ORB-Template.md** only (`First-ORB-Template` is retired).
5. Boot: User-Record → README → Shard → ORB.
6. Issues may be reported; merge requests considered. No support beyond sharing at this point.

## User-Record (per user)

Pointers only — no journal bodies.  
Update last-open when a journal subject is opened or continued.

## ORB

Blank-ORB-Template is the single blank. Session ORBs live in Orb History.

## Accountability

object-log backups only on ORB update. system-log = 7-day pointers.
