## 1. Purpose

This Crystal defines what an ORB is, how it is created, used, and related to Crystals.

## 2. Core Definition

An **ORB** is an external working file that lives outside the live conversation.

The live conversation is temporary.  
An ORB holds the important working material we want to keep available: current reasoning, decisions, open questions, process notes, and continuity.

- It initially lives in the session artifacts.
- A new blank ORB can be provided on install.
- It is important but optional.
- It supports versioning and tracking of the context window.
- It only needs updating once in a while.
- It should actively help reveal limits of the current AI or environment.
- Later it can be used to create more permanent project knowledge (Crystals).
- Finished or important ORBs are saved into the user’s My-Dragon history.

ORBs (and Crystals) can contain conversations, summaries, thread summaries, sources of materials, and links to any other information the user has access to and requests.
