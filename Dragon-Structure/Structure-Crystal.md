## 1. Purpose

This Crystal records the organizational choices that underpin a Dragon installation, especially the use of PARA and how My-Dragon sits inside it.

## 2. Why PARA was chosen

PARA (Projects • Areas • Resources • Archives) provides a simple, durable way to separate:

- **Projects** — efforts with a finish line or clear active focus
- **Areas** — ongoing responsibilities with no finish line
- **Resources** — reference material
- **Archives** — inactive or completed material

It is not required by Dragon. It is the structure this owner chose because it matches how the work actually happens.

## 3. Rules for an AI

- Respect the existing PARA layout when filing or proposing new durable objects.
- Prefer placing new project Crystals inside or clearly linked to the appropriate Project or Area.
- Do not force PARA on a user who has chosen a different structure. Dragon should adapt.
- When in doubt, ask before creating new top-level organizational folders.
